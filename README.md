# 대한민국 산업 공급망 분석 및 수입의존도 진단 시뮬레이터

2023년 한국은행 산업연관표(연장표)를 활용해 국내 산업의 생산·부가가치·수입 유발효과와 수입 중간재 투입 구조를 살펴보는 정적 웹앱입니다.

## 주요 기능

1. **산업구조 대시보드**: 분류별 산업 수, 평균 수입 중간재 투입률, 평균 생산·부가가치 유발계수와 상위 산업 비교
2. **산업별 상세 분석**: 산업별 주요 국산·수입 중간재 투입 및 생산·부가가치 파급 산업 확인
3. **산업 간 파급효과**: 생산유발계수, 부가가치유발계수, 수입유발계수, 수입 중간재 투입률 순위
4. **수요충격 시뮬레이터**: 산업과 최종수요 증가액을 선택해 생산·부가가치·수입 유발액 추정
5. **가공 데이터 탐색**: 산업별 지표 검색·정렬 및 CSV 다운로드
6. **원본 엑셀 탐색**: 대분류·중분류·소분류·기본부문 원본 Excel을 불러와 12개 시트를 선택하고 검색·확인·CSV 저장

## 데이터 및 분류

- 기준연도: 2023년
- 가격 기준: 생산자가격
- 분류: 통합대분류(33부문), 통합중분류(83부문), 통합소분류(165부문), 기본부문(380부문)
- 원자료: 한국은행 「2023년 산업연관표(연장표) 작성 결과」의 투입산출표 Excel
- `data/industry-data.json`은 원자료의 총투입계수, 국산·수입 투입계수, 생산·부가가치·수입 유발계수표를 산업별 지표와 상위 연관 산업 형태로 가공한 파일입니다.
- `data/io-2023-*.xlsx`는 원본 엑셀 탐색 메뉴에서 불러오는 원자료입니다.

## 실행 방법

GitHub Pages에 게시하면 별도 서버 없이 실행됩니다. 저장소 최상위에 `index.html`, `style.css`, `app.js`, `excel-explorer.html`, `excel-explorer.js`, `excel-explorer.css`, `README.md`를 두고, `data/` 폴더 안에 `industry-data.json` 및 네 개의 `io-2023-*.xlsx` 파일을 유지하세요.

원본 Excel을 확인하려면 왼쪽 메뉴의 **원본 엑셀 탐색**을 누르고 분류를 선택한 다음 **선택한 엑셀 불러오기** 버튼을 누릅니다. 시트 선택 메뉴에서 12개 시트 중 하나를 고르고 검색창에 산업명·코드·값을 입력할 수 있습니다. 열이 많은 표는 이전/다음 열 버튼으로 이동하고, 현재 시트는 CSV로 저장할 수 있습니다. 내 컴퓨터의 Excel 파일을 직접 선택하는 기능도 제공합니다.

## 분석 방법과 해석상 유의점

- **수입 중간재 투입률**: 수입 중간재 투입액을 해당 산업의 총산출액으로 나눈 값입니다. 산업의 생산 과정에서 수입 중간재가 차지하는 직접 투입 비중을 파악하는 데 활용합니다.
- **생산유발계수**: 해당 산업 최종수요 1단위 증가에 따라 전 산업에서 직·간접적으로 유발되는 생산액의 크기입니다.
- **부가가치유발계수**: 해당 산업 최종수요 1단위 증가에 따라 전 산업에서 직·간접적으로 유발되는 부가가치의 크기입니다.
- **수입유발계수**: 해당 산업 최종수요 1단위 증가에 따라 전 산업에서 직·간접적으로 유발되는 수입액의 크기입니다.
- 시뮬레이터는 공표된 유발계수에 사용자가 입력한 최종수요 증가액을 곱하는 정태적 계산입니다. 가격과 산업별 투입구조가 일정하다는 산업연관분석의 가정에 기반하며, 실제 정책 효과나 미래 예측치와 동일하지 않습니다.
- 원자료의 금액 단위는 백만원입니다. 시뮬레이터는 유발계수에 사용자가 입력한 최종수요 증가액(억원)을 곱해 결과를 억원으로 표시합니다.
- 산업연관표는 당해년 가격 기준이므로 다른 연도와의 실질 성장률 비교에 그대로 사용하지 않도록 유의해야 합니다.
- 취업·고용유발계수는 이번 웹앱 데이터 파일에 포함된 투입산출표 계수만으로 산출하지 않으므로 표시하지 않습니다.
- 원본 엑셀 탐색 기능은 원자료의 셀 값을 보여주는 기능이며, 기존 대시보드의 가공 데이터나 계산 결과를 자동으로 변경하지 않습니다.
